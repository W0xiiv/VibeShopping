# VibeShopping Mini App — MVP

Это стартовый проект Telegram Mini App: веб-интерфейс + API + Telegram-бот для запуска приложения.

## Уже реализовано
- Адаптивный интерфейс, открываемый внутри Telegram.
- Выбор фотографии товара.
- Отправка изображения на сервер.
- Распознавание товара и создание поисковых запросов через vision-модель.
- Ссылки на поиск в Wildberries, Ozon и Яндекс Маркете.
- Проверка подписи Telegram `initData` на сервере.
- Кнопка запуска Mini App из чата с ботом.

## Пока не реализовано
Автоматическое извлечение карточек, актуальных цен, рейтингов и отзывов с маркетплейсов. Сейчас создаются поисковые ссылки. Не выдавайте эти ссылки за готовое сравнение цен.

## Требования
- Python 3.10+
- Telegram-бот, созданный через `@BotFather`
- API-ключ модели, которая поддерживает изображения
- Публичный HTTPS URL для Mini App

API-ключ нейросети может оплачиваться отдельно от подписки ChatGPT. Бесплатность всего сервиса не гарантируется: бесплатный MVP означает отсутствие платных функций в коде, но сервер и API могут иметь ограничения/расходы.

## Установка локально

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Затем:
```bash
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и заполни значения.

## Запуск веб-приложения

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Проверка:
- `http://localhost:8000/`
- `http://localhost:8000/health`

Локальный адрес не откроется в Telegram у других пользователей. Для Telegram нужен публичный HTTPS адрес. На этапе разработки можно использовать HTTPS-туннель, а для постоянной работы — хостинг.

## Запуск Telegram-бота

В другом терминале:
```bash
python -m app.bot
```

Бот отправит кнопку Mini App, ведущую на `WEBAPP_URL`.

Альтернативно можно настроить Menu Button в `@BotFather` командой `/setmenubutton`, указав публичный HTTPS URL приложения.

## Безопасность
- Никогда не публикуй `.env`, токен бота или API-ключ.
- Сервер проверяет Telegram `initData` через HMAC и срок действия.
- Не доверяй `initDataUnsafe` на клиенте как доказательству личности.
- Не отключай проверку `initData` на сервере.
- Перед публичным запуском добавь rate limiting, лимиты расходов, мониторинг и политику хранения/удаления загружаемых изображений.
